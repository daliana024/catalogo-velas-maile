CÓMO FUNCIONA:
- Cada vela puede seguir teniendo varias categorías.
- Para ordenar, el catálogo toma la categoría de mayor prioridad de la lista anterior.
- Ejemplo: Baby Shower + Personalizadas se agrupa con Baby Shower.
- Dentro de cada grupo se respeta primero el campo Orden del administrador.
- No se muestran encabezados de sección: las fotos simplemente quedan juntas de forma natural.
- Las categorías antiguas Detalles especiales, Aromatizadas y Hechas con amor ya no se muestran ni se pueden seleccionar.
- Al editar y guardar una publicación antigua, esas categorías obsoletas se eliminan de sus etiquetas.

NUEVA CATEGORÍA:
- Corporativas: para empresas, marcas, eventos empresariales, regalos institucionales y detalles para colaboradores/clientes.

RENDIMIENTO:
- Se precargan las fotos vecinas del carrusel.
- El swipe usa Pointer Events para mayor precisión.
- Las primeras portadas tienen prioridad de carga.
