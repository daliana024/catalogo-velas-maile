VELAS MAILE - PROYECTO COMPLETO
================================

ARCHIVOS PRINCIPALES
- index.html       : catálogo público
- estilos.css      : estilos del catálogo
- script.js        : carga productos desde Supabase y abre el detalle
- admin.html       : panel de administración
- admin.css        : estilos del administrador
- admin.js         : login, publicar, editar y eliminar productos
- supabase-config.js : conexión con Supabase
- imagenes/        : portada, logo e imágenes locales
- fuentes/         : fuente Hello Honey

IMPORTANTE SOBRE SUPABASE
Este proyecto usa la estructura que ya tenías:
- titulo
- precio
- descripcion
- etiquetas
- imagenes
- orden
- created_at

No requiere una columna nueva llamada "empaque".
El administrador guarda el EMPAQUE dentro de la columna "descripcion".
El catálogo lo muestra visualmente como "Empaque".
